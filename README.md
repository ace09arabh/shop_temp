# 🛍️ Shopsy – Online Shopping Website

## 📌 About the Project
Shopsy is a simple online shopping website developed using HTML, CSS, and JavaScript. It allows users to browse different products, view product details, check prices, and explore a basic shopping interface.

## 🌐 Live Website
**Live Demo:** https://ace09arabh.github.io/shop_temp/

## ✨ Features
- 🏠 Home page with a product collection
- 🖼️ Clickable product images
- 📄 Individual product details
- 💰 Product prices and descriptions
- 🔢 Quantity selection
- 🛍️ Basic Add to Cart functionality
- 🔐 Login page interface
- 📱 Simple, user-friendly design

## 🧰 Technologies Used
- **HTML** – Website structure
- **CSS** – Styling and layout
- **JavaScript** – Product details and interactions
- **GitHub Pages** – Website hosting (for supported static pages)

## 📦 Products
The website includes products such as:
- Headphones
- Laptop and phone covers
- Smartphones
- PC RAM
- T-shirts
- Jeans
- Pendrives
- Snacks and other products

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

The main objective of this project is to learn and practice frontend web development, including webpage design, product presentation, JavaScript interactions, and GitHub-based deployment.
